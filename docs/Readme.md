# **Pet Adoption Prediction**

## **Business Needs**

**Компанія-Замовник:** Best Friends Animal Society

Best Friends Animal Society прагне підвищити ймовірність усиновлення тварин у притулках, мінімізуючи час їхнього перебування там. Для цього необхідна модель машинного навчання, яка на основі характеристик тварин передбачатиме їхні шанси на усиновлення. Це допоможе ефективніше працювати з кожною твариною, адаптуючи підходи до догляду і реклами для максимізації ймовірності знайти нову домівку.

## **Installing**

Для встановлення проєкту виконайте наступні кроки:

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/your-username/pet-adoption-prediction.git
   ```
2. Перейдіть у директорію проєкту:

   ```bash
   cd pet-adoption-prediction
   ```

Переконайтеся, що на вашому комп'ютері встановлений Python (версія 3.7 або вище) і пакетний менеджер pip, перш ніж продовжувати встановлення.

3. Встановіть всі необхідні залежності з файлу <code>requirements.txt:</code>

   ```bash
   pip install -r requirements.txt
   ```

## Використання

У папці "pipeline" знаходяться два скрипти - `train.py` та `predict.py`.

- `train.py`: Використовується для тренування моделі машинного навчання на тренувальних даних. Після виконання скрипта з'являться файли `param_dict.pickle` та `finalized_model.sav`, що зберігають модель і параметри обробки даних.

- `predict.py`: Використовується для передбачення на нових даних, що знаходяться у файлі `new_data.csv`. Після виконання скрипта результати зберігаються у `prediction_results.csv`.

Дані (навчальні та тестові) повинні бути розміщені у папці "data".

1. Тренування моделі

Щоб розпочати тренування моделі, переконайтесь, що ваші дані для тренування розміщені у файлі `data/train_data.csv`. Виконайте наступну команду:

```bash
python pipeline/train.py
```

Після виконання скрипта у папці `models` з'являться наступні файли:

`param_dict.pickle`: Зберігає параметри для підготовки даних, які необхідні для передбачення.

`finalized_model.sav`: Збережена модель, яку можна використовувати для прогнозування на нових даних.

2. Передбачення на нових даних

Передбачення можна виконати на новому наборі даних `data/new_data.csv`. Щоб виконати передбачення, запустіть:

```bash
python pipeline/predict.py
```

Результати передбачення зберігаються у файлі `data/prediction_results.csv`. Цей файл буде містити передбачені значення для `AdoptionSpeed` (колонка `AdoptinSpeed_pred`).

3. Аналіз результатів

Для аналізу результатів передбачення виконайте:

```bash
python utils/analyze_results.py
```

## Особливості

Модель, що використовується тут, - це `RandomForestClassifier`, налаштований за допомогою найкращих гіперпараметрів, знайдених на основі попереднього аналізу. Передбачення засноване на характеристиках тварин, таких як вік, порода, здоров'я, поведінка та інші значимі фактори, щоб оцінити ймовірність усиновлення.
